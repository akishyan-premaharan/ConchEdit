# ConchEdit 

**A developer ecosystem compatible for everyone**

*OpenBSD, MacOS, Windows, Linux*

<br>

## What is ConchEdit?

Asides from some code triggers, ConchEdit is a developer environment written entirely in BASH that features: 

- 🔄  **Version control**
  
- 🖥️  A **replica of a terminal** application inside a terminal!
  
- 🖋️  Syntax Highlighting
  
- 📄  Access to editors such as GNU's **Nano/Vim**

## How to run this Project?

To run this project, you can: 

- Download this file and run it via Terminal (Git Bash for Windows Users):
```
bash conchedit.sh 
```
- **OR** run it on a Linux VM (Such as [**WebVM**](https://webvm.io/), the VM used when I was testing the project), and enter the same command
```
bash conchedit.sh 
```
